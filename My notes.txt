## 🏃 Quick Start Guide

### 1. Launch Docker Services (Postgres + Backend + Web)
Open Docker Desktop on your machine, then run from `c:/Bookmart`:
```bash
docker compose up --build
```
- **Web**: [http://localhost:3000](http://localhost:3000) or [http://192.168.1.102:3000](http://192.168.1.102:3000)
- **Backend API**: [http://localhost:8000/api/v1/](http://localhost:8000/api/v1/)
- **Swagger Docs**: [http://localhost:8000/api/schema/swagger-ui/](http://localhost:8000/api/schema/swagger-ui/)

### 2. Create Django Superuser
```bash
docker compose exec backend python manage.py createsuperuser
```

### 3. Run Mobile App (Expo Go on Physical Phone)
```bash
cd bookmart-app
npx expo start
```
Scan the QR code with **Expo Go** (Android) or **Camera** (iOS).

### 4. When Changing Wi-Fi Networks
If your IP changes in the future:
1. Update `HOST_IP=YOUR_NEW_IP` in root [`.env`](file:///c:/Bookmart/.env).
2. Update `API_URL=http://YOUR_NEW_IP:8000/api/v1` in [`bookmart-app/.env`](file:///c:/Bookmart/bookmart-app/.env).
3. Rebuild and start containers: `docker compose up --build -d`.






Here is how to run the different parts of the Bookmart project:

Option 1: Run with Docker Compose (Recommended)
This starts the PostgreSQL Database, Django Backend, and Next.js Web Frontend in isolated containers.

powershell
# 1. Navigate to the root directory
cd c:\Bookmart
# 2. Build and start all containers in detached mode
docker compose up --build -d
# 3. Check status of the running containers
docker compose ps
# 4. View real-time logs (optional)
docker compose logs -f
Option 2: Run the Mobile App (

bookmart-app
) (Expo / React Native)
Configure Environment Variables: In 

/c:/Bookmart/bookmart-app/.env
, set your computer's local Wi-Fi IP address so your physical phone running Expo Go or emulator can connect to the backend:

env
API_URL=http://<YOUR_LAN_IP>:8000/api/v1
(Run ipconfig in terminal to find your IPv4 Address, e.g. 192.168.1.102)

Start the Expo Development Server:

powershell
cd c:\Bookmart\bookmart-app
npm install
npm start
Press a for Android Emulator
Press w for Web
Or scan the QR code using the Expo Go app on your physical mobile phone.
Option 3: Run Services Locally Without Docker
If you prefer running services directly on your host machine without Docker:

1. Backend (Django REST API)
powershell

2. Web Frontend (Next.js)
powershell
